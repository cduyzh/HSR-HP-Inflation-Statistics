# Agent 文档索引

本目录是面向 AI agent 与后续维护者的专题文档。根目录 [AGENTS.md](../../AGENTS.md) 是项目总览；本目录按主题展开细节。

| 文档 | 内容 |
| --- | --- |
| [data-source.md](./data-source.md) | 数据源协议、缓存分层、版本策略、怪物图片与富文本处理 |
| [statistics.md](./statistics.md) | 四种模式的统计口径、HP 公式、星启节点、无限波、赛季去重 |
| [ui-interaction.md](./ui-interaction.md) | 路由、页面/组件职责、滚动与布局约束 |
| [workflow.md](./workflow.md) | 开发/测试/部署命令、排障手册、常见变更的检查清单 |

修改代码前，建议先读与改动区域对应的文档；修改后如果口径或协议变了，同步更新对应文档与根 `AGENTS.md`。
